# 🧮 Web-Based GST Calculator

A clean, light-weight, and responsive web application designed for fast numerical calculations and quick tax computations. Built using pure HTML, CSS, and Vanilla JavaScript with zero external dependencies.
## Features
- Standard basic math calculations (`+`, `-`, `×`, `÷`)
- Dedicated **+GST (18%)** and **-GST (18%)** buttons for quick tax computation
- Responsive design styled using CSS grid/tables
- Clean error-handling for invalid math expressions

## Usage
Simply open `index.html` in any modern browser or host it via GitHub Pages.

### ✨ Highlights
- **GST Calculations:** Dedicated single-click buttons for adding (`+18%`) and removing (`-18%`) GST.
- **Mathematical Operators:** Full support for basic operations (`+`, `-`, `×`, `÷`) with proper symbol formatting.
- **Form Validation & Error Handling:** Prevents runtime errors on invalid inputs with automatic display resets.
- **Modern UI:** Styled with dynamic hover states and a responsive layout centered for all screen sizes.x
