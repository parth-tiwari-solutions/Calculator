# GST Calculator

A sleek, responsive web-based calculator built with HTML, CSS, and JavaScript featuring instant 18% GST addition and removal options.

## Features
- Standard basic math calculations (`+`, `-`, `×`, `÷`)
- Dedicated **+GST (18%)** and **-GST (18%)** buttons for quick tax computation
- Responsive design styled using CSS grid/tables
- Clean error-handling for invalid math expressions

## Usage
Simply open `index.html` in any modern browser or host it via GitHub Pages.
